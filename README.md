## 🚀 Featured Projects

### 🤖 [AI-Powered Smart Attendance System](https://github.com/elshhawy/AI-Powered-Smart-Attendance-System)
> *DEPI Graduation Project — Team Lead of 6*

Real-time face recognition combined with a RAG-powered bilingual chatbot (Arabic + English). Production-ready system built with FastAPI, ArcFace 512-dim embeddings, FAISS vector search, anti-spoofing liveness detection — fully containerized with Docker Compose. Raw face images are **never stored** — only embedding vectors.

`FastAPI` `ArcFace` `RetinaFace` `FAISS` `LLaMA 3 (Groq)` `PostgreSQL` `Docker` `Streamlit` `JWT`

---

### 💳 [Credit Card Fraud Detection](https://github.com/elshhawy/credit_card_fraud_project)

Fraud detection on a **559:1 class imbalance** dataset. Evaluated 7 sampling strategies × 5 models with StratifiedKFold CV. Achieved **ROC-AUC 0.9736**, **PR-AUC 0.8620**, and **F1-Score 0.8646** using XGBoost with `scale_pos_weight` — no resampling needed. Threshold optimized via Precision-Recall Curve + isotonic regression calibration. Reduced Amount skewness from **19.99 → 0.16** via log transform.

`XGBoost` `Scikit-learn` `Pandas` `StratifiedKFold` `Imbalanced Learning`

---

### ❤️ [Heart Disease Prediction](https://github.com/elshhawy/Heart-Disease-Prediction)

Production-aware binary classification on **918 patient records** with **zero data leakage** (sklearn.Pipeline — scaler fitted on train only). Benchmarked 5 models; Logistic Regression achieved **91.3% test accuracy**, **AUC 0.970**, and **5-fold CV AUC 0.930 ± 0.023**. Config-driven YAML hyperparameters + full **pytest** unit & integration coverage + serialized inference.

`Scikit-learn` `pytest` `YAML Config` `Serialized Inference` `Stratified CV`

---

### 🚕 [NYC Taxi Trip Duration Prediction](https://github.com/elshhawy/elshhawy-NYC_Taxi_Trip_Duration----regression_project)

Regression pipeline on **1,000,000+ NYC taxi records**. Engineered 15+ features including haversine distance, cyclical time encoding, rush-hour flags, and **100 KMeans route clusters** for spatial patterns. Achieved Validation **R² = 0.7638** and **RMSE = 0.3524** (log scale). Applied strict cleaning: speed ≤ 80 km/h, duration 60s–3hrs, NYC geo-bounds.

`Ridge Regression` `KMeans` `Feature Engineering` `Pandas` `NumPy`

---

### 📰 [Intelligent News Content Classification](https://github.com/elshhawy/Intelligent-News-Content-Classification-and-Summarization-System)

Deep learning NLP system classifying **20,000+ news articles** across multiple categories. LSTM and GRU models achieved **88% validation accuracy** and **F1-score 0.86**. Reduced overfitting by **25%** via dropout regularization and sequence padding optimization.

`TensorFlow` `Keras` `LSTM` `GRU` `NLP` `Text Classification`
