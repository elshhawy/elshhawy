### 1. AI-Powered Smart Attendance System
**DEPI Graduation Project | Team Lead**

An AI-powered attendance platform combining real-time face recognition with a bilingual RAG-based chatbot.

- Face detection and recognition using RetinaFace and ArcFace.
- 512-dimensional facial embeddings.
- Vector similarity search using FAISS.
- Anti-spoofing and liveness detection.
- Bilingual Arabic/English AI assistant.
- Backend architecture using FastAPI and PostgreSQL.
- Containerized services using Docker Compose.
- JWT-based authentication.

**Tech Stack:** `Python` `FastAPI` `RetinaFace` `ArcFace` `FAISS` `Groq` `LLaMA 3.3` `PostgreSQL` `Docker` `React`

- Threshold optimization and probability calibration.
